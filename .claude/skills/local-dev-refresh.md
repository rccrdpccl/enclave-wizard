# Local Dev Refresh (enclave-mock)

Runs the wizard against `enclave-mock/` (noop'd ansible tasks from the real enclave repo) on port 5443. This is different from demo mode (`make demo` on port 3443) — enclave-mock has real playbooks with noop tasks, while demo mode replays recorded runs.

## When to use which

| Mode | Command | Port | Backend | Use for |
|------|---------|------|---------|---------|
| Demo | `make demo` | 3443 | Recorded replays at 10x speed | UI dev, manual walkthrough |
| Dev (enclave-mock) | `make dev` | 3443 | Noop ansible tasks | Testing config write, validation flows |
| Dev (real enclave) | `make run` | 3443 | Real ansible | Full integration testing |

## Quick Refresh

### First time: generate enclave-mock

```bash
test -d enclave-mock || make enclave-mock
```

To regenerate from a specific branch:
```bash
make clean-enclave-mock
make enclave-mock ENCLAVE_MOCK_BRANCH=<branch>
```

### Start

```bash
make dev
```

This builds the UI, builds the Go binary with dev tags, and starts the wizard in the foreground with `--no-auth` against `enclave-mock/`.

### Backend-only restart (no UI changes)

```bash
pkill -f 'enclave-wizard.*--no-auth' 2>/dev/null; sleep 1
go build -ldflags='-w -s' -tags dev -o enclave-wizard .
./enclave-wizard --enclave-dir enclave-mock \
  --tls-cert hack/tls/server.crt --tls-key hack/tls/server.key \
  --no-auth --password-file /tmp/enclave-wizard-dev-pass
```

## Notes

- Go and Node.js run inside `distrobox enter osac` — not available on the host
- The UI is embedded at build time — UI changes require rebuilding both UI and binary
- TLS certs auto-generated by `make dev` if missing
- `ansible-runner` is not available locally — schema validation is skipped
- `enclave-mock/` is gitignored
